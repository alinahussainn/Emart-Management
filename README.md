# Emart Management System 🛒
Emart is a Java-based desktop application designed to manage day-to-day operations of a retail store. The system provides role-based access for Managers and Receptionists, ensuring secure and efficient handling of store activities.

## Features 🌟
- **Sales Tracking
- **Automated Reordering
- **Price Management
- **Barcode Scanning
- **Inventory Management
- User Access Control
- **Real Time Stock Updates
